# Security policy

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/CanerKocak/clanker-skills/security/advisories/new)
for vulnerabilities in a bundled script, template, workflow, or instruction
that could cause unsafe execution. Include the affected skill, a minimal
reproduction, the expected boundary, and the observed impact.

Do not publish an exploitable report in a public issue before it has been
triaged. Ordinary documentation errors, missing integrations, and workflow
suggestions belong in the public issue tracker.

Only the current default branch is supported. Reports about upstream projects
should be sent to the relevant upstream maintainer unless the bundled copy is
independently affected.
