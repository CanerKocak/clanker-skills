# Deepen a prompt

Before rewriting, give a brief, task-specific answer to each question.

1. **What would an experienced practitioner do that the brief leaves out?**
   Name a decision or step that could change the result. Explain why it
   matters. If the brief already covers it, identify the choice to keep.
2. **What would they start from?** Name the material closest to the subject,
   such as an original passage, a receipt, or a direct observation. If only a
   summary is available, identify the missing source and what remains uncertain.
3. **How would they use that material?** Name the technique and any tool it
   needs. Describe the operation precisely enough for someone else to repeat.
4. **What would show the result holds up?** Identify an independent record,
   test, or observable effect. Say what finding would support the result or
   call it into question. For creative work, tie the check to the intended
   effect on the audience.

Write one prompt that can stand on its own. Put those choices to work within
the original goal, audience, deliverable, and constraints. End with the rewrite
unless the user also asks you to carry it out.
